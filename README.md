# DESKA_INT

**Ручная доска для построения карты связей при OSINT-исследовании.**

Идейный аналог Maltego, но без автоматических «трансформов» — все сущности
и связи вы добавляете сами. Работает полностью локально: один HTML-файл,
никаких зависимостей, установки и интернета.

## Что это

Учебная OSINT-доска: вы добавляете сущности (персоны, e-mail, телефоны,
домены, IP-адреса и любые свои типы), соединяете их подписанными связями
и получаете наглядную карту дела. По итогу работы доска выгружается
в отчёт `.md` или картинку `.png` / `.jpg` — легко вставить в курсовую,
отчёт или презентацию.

> ⚠️ **Только для образовательных целей.** Работайте исключительно
> с открытыми источниками. Не используйте инструмент для слежки,
> давления или деанонимизации частных лиц.

## Возможности

### Сущности и связи
- 10 встроенных типов сущностей: **Персона**, **Организация**, **E-mail**,
  **Телефон**, **Никнейм**, **Домен**, **IP-адрес**, **Локация**,
  **Кошелёк**, **Документ**.
- **Свои типы** — с любым названием, коротким обозначением (1–3 символа)
  и цветом. Тип можно редактировать и удалять.
- Связи с подписью (глагол: «использует», «зарегистрирован на», …)
  или любой свой текст.
- У каждой связи — редактирование подписи (ЛКМ) и удаление (ПКМ).

### Работа с информацией
- **Поиск по узлам** — по значению, заметке и ссылке на источник.
  `Enter` — следующее совпадение, `Esc` — очистить.
- **Статус достоверности** у каждого узла: Подтверждено / Не подтверждено /
  Слух. Визуально — цветная полоса слева.
- **Сквозная нумерация** — узлы нумеруются 1, 2, 3… Номер виден на доске,
  в свойствах и в отчёте; удобно ссылаться на «узел №7».
- **Источник и заметка** у каждой сущности — попадают в отчёт.

### Строгая структура (борьба с «слипаниями»)
- **Привязка к сетке** — узлы встают на сетку 20 px при добавлении
  и перетаскивании.
- **Связи под 90°** — ортогональные линии, как в блок-схемах.
- **Отталкивание узлов** — при перетаскивании соседи автоматически
  расходятся с запасом (≈44 px по горизонтали, ≈38 px по вертикали),
  наложений не остаётся даже до того, как узлы подошли вплотную.

### Автораскладка
Три режима одним кликом:
- **Кругом** — все узлы по окружности вокруг центра.
- **Деревом** — иерархия сверху вниз; корень — узел с наибольшим
  числом связей, изолированные узлы уходят в самый низ.
- **Сеткой** — ровные ряды, `cols = ceil(√N)`.

### Оформление
- **Тёмная и светлая темы** — переключение одной кнопкой, выбор
  запоминается.

### Данные и экспорт
- **Автосохранение** в `localStorage` браузера.
- **Экспорт / импорт JSON** — для переноса карты между устройствами.
- **PNG / JPG** — вся доска картинкой в текущей теме, без шапки и панели,
  масштаб 2× для чёткости.
- **Отчёт `.md`** — таблица сущностей (с достоверностью, ссылками,
  заметками) и список связей с номерами узлов.

## Быстрый старт

1. Скачайте репозиторий или только файл `index.html`.
2. Откройте `index.html` двойным щелчком в браузере
   (Firefox, Chrome, Edge — любой).
3. Нажмите **«Демо-пример»**, чтобы увидеть готовую карту,
   или **«Очистить»** и начните своё дело.

Установка не требуется. Интернет не нужен.

```bash
git clone https://github.com/<ваш-логин>/deska-int.git
cd deska-int
# Откройте osint-board/index.html в браузере
```

## Управление

| Действие ↕▾ | Как ↕▾ |
|---|---|
| −Добавить сущность | Клик по кнопке в палитре слева |
| −Свой тип сущности | «Мои типы» → «+ Добавить свой тип» |
| Редактировать / удалить свой тип | Кнопки ✎ и × рядом с типом |
| Переместить узел | Перетащить мышью |
| Создать связь | Потянуть за синюю точку справа от узла к другому узлу |
| Изменить тип связи | ЛКМ по подписи на линии |
| Удалить связь | ПКМ по подписи на линии |
| Удалить узел | ПКМ по узлу или клавиша `Del` |
| Масштаб | Колесо мыши |
| Сдвинуть полотно | Перетащить пустое место |
| Сбросить вид | Кнопка «Центрировать» |
| Переключить тему | Кнопка с иконкой солнца/луны в шапке |
| Поиск | Поле в шапке, `Enter` — следующее совпадение, `Esc` — очистить |
| Экспорт PNG / JPG | Кнопки «PNG» и «JPG» в шапке |
| Экспорт отчёта | Кнопка «Отчёт .md» |
⚙

## Формат отчёта

Кнопка «Отчёт .md» выгружает файл `DESKA_INT_report.md`:

```
# Название дела

**Исполнитель:** ФИО
**Дата выгрузки:** 27.10.2026
**Сущностей:** 10 · **Связей:** 10

## Сущности

| № | Тип | Значение | Достоверность | Источник | Заметка |
|---|---|---|---|---|---|
| 1 | Персона | Иванов Иван | Подтверждено | — | — |
| 2 | E-mail | i.ivanov@example.com | Подтверждено | — | — |
...

## Связи

- (1) **Иванов Иван** → *использует* → (2) **i.ivanov@example.com**
...
```

Отчёт открывается в любом Markdown-редакторе и легко конвертируется
в Word или PDF.

## Методика работы (типовой порядок)

1. Определите цель: что устанавливаем — личность, организацию,
инфраструктуру.
2. Добавьте центральный узел («Персона» или «Организация»).
3. По каждому найденному факту — отдельная сущность, связь подписывайте
глаголом.
4. В поле **«Источник»** вставляйте прямую ссылку на страницу,
откуда взяты данные.
5. Непроверенные сведения помечайте статусом **«Не подтверждено»**
или **«Слух»**.
6. Перед выводами пройдитесь по карте и уберите узлы без источника.

## Правовая и этическая рамка

- Работайте только с **открытыми источниками**.
- Не публикуйте персональные данные третьих лиц
(152-ФЗ, ст. 137 УК РФ).
- Не используйте инструмент для слежки, давления или деанонимизации.
- Учебные примеры оформляйте **вымышленными** данными:
домен `example.com`, IP из диапазонов TEST-NET
(`192.0.2.0/24`, `198.51.100.0/24`, `203.0.113.0/24`).

## Чего доска НЕ делает

- Не собирает данные автоматически (нет парсинга, API-запросов,
трансформов).
- Не проверяет достоверность связей — это ручная работа аналитика.
- Не строит граф по загруженному файлу: импорт только своего формата JSON.
